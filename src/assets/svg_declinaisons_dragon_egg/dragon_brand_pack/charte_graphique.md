# Charte graphique — Dragon Egg

## Contenu du pack
- `logo_dragon_egg_transparent.svg` : logo principal
- `icon_dragon_egg_transparent.svg` : version icône
- `motif_background_transparent.svg` : motif répétable de fond
- `copyright_notice.txt` : notice de copyright éditable

## Particularité de cette version
Toutes les zones blanches du SVG ont été remplacées par de la transparence :
- fond blanc supprimé
- parties blanches internes rendues transparentes

## Usage recommandé
### Fond
- idéal sur fond sombre ou coloré
- possible sur fond clair si le trait est recoloré

### Couleur du logo
Version livrée :
- trait principal : noir `#000000`
- intérieur : transparent

Déclinaisons recommandées :
- noir sur fond clair
- blanc sur fond sombre
- primary / accent pour intégration UI

### Zone de protection
Laisser un espace libre autour du logo équivalent à environ la largeur d’un œil du dragon.

### Taille minimale
- Icône : 24 px minimum
- Logo complet : 96 px minimum conseillé

### Motif de fond
Utiliser le motif avec une opacité faible ou sur un fond déjà texturé.
Il fonctionne bien en :
- arrière-plan de section
- splash screen
- écran de chargement
- overlay décoratif

## Conseil technique
Le SVG peut être recoloré facilement en modifiant les valeurs de `stroke`.
